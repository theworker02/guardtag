# guardtag

Guard filesystem tag paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/guardtag/

## Install / run

```bash
git clone https://github.com/theworker02/guardtag.git
cd guardtag
node src/cli.js
node --test
```
